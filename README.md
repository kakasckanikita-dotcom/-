# Пыль и Свинец

3D-вестерн с открытым миром на Godot 4.3. Территория Мескаль, 1889 год.
Вы — Эли Брэнсон, охотник за головами.

## Скачать APK для Android

APK собирает GitHub Actions (`.github/workflows/android.yml`) при каждом пуше в `godot/`:

1. Откройте вкладку **Actions** → последний запуск **Android APK** → внизу раздел **Artifacts** → `PylISvinec-apk`.
2. Распакуйте zip, перенесите `PylISvinec.apk` на телефон и установите
   (Android попросит разрешить установку из неизвестных источников).

Чтобы APK появился на странице **Releases** (удобно качать прямо с телефона), поставьте тег:
`git tag v1.0 && git push origin v1.0`.

Сборку можно запустить и вручную: **Actions → Android APK → Run workflow**.
APK подписан отладочным ключом, этого достаточно для установки на свой телефон;
для Google Play нужен собственный ключ.

## Запуск на ПК

1. Установите [Godot 4.3+](https://godotengine.org/download) (обычная версия, не .NET).
2. В менеджере проектов нажмите «Импорт» и выберите `godot/project.godot`.
3. Нажмите F5.

## Что есть в игре
- Мир 1×1 км: пустыня, столовые горы на горизонте, река с тремя мостами, дороги
- Два города («Пыльный Ручей», «Медная Гора»): салун, лавка, контора шерифа, банк, гостиница
- Восемь бандитских лагерей с палатками и костром, после зачистки они заселяются снова
- Конь Буран: можно сесть и слезть, есть галоп, на свист прибегает
- Камера от третьего лица, стрельба через прицел, выстрел в голову наносит тройной урон
- «Глаз ястреба»: время замедляется, вы отмечаете цели, затем залп по всем
- Розыск за головы у шерифа и награда за главаря
- Закон: за преступления дают звёзды розыска и приходит конная погоня
- Смена дня и ночи: солнце, закат, луна, фонарь героя, костры лагерей
- Миникарта, большая карта, автосохранение

## Управление

| ПК | Телефон | Действие |
|---|---|---|
| WASD | джойстик слева | движение |
| мышь | палец справа | камера |
| ЛКМ | ОГОНЬ | выстрел (на телефоне с доводкой прицела) |
| Shift (держать) + щелчки по целям | ГЛАЗ (держать) + касания целей | «Глаз ястреба» |
| E | ДЕЙСТВИЕ | конь, двери |
| Пробел | ГАЛОП | галоп верхом |
| H | СВИСТ | позвать коня |
| R / Q / F | ЗАРЯД / АПТЕЧКА / ТОНИК | перезарядка / лечение / концентрация |
| M или Tab | КАРТА | карта |

## Устройство проекта (`godot/`)

| Файл | Что делает |
|---|---|
| `scenes/main.tscn` | главная сцена: мир и интерфейс |
| `scripts/game.gd` | автозагрузка `Game`: характеристики, розыск, время, звуки, сохранение, сенсорный ввод |
| `scripts/world.gd` | генерация мира, освещение и небо, лагеря, погоня |
| `scripts/player.gd` | герой: камера, езда, стрельба, «Глаз ястреба» |
| `scripts/npc.gd` | бандиты, главари, горожане, шерифы, конная погоня |
| `scripts/rig.gd` | персонажи на скелете Mixamo с анимацией кодом |
| `scripts/models.gd` | загрузка моделей: подгонка размера, удаление встроенной земли |
| `assets/models/` | модели с Sketchfab (см. CREDITS.md) |
| `scripts/horse_model.gd`, `horse.gd` | модель коня и конь героя |
| `scripts/hud.gd`, `minimap.gd`, `touch.gd` | интерфейс, карты, сенсорные кнопки |
| `scripts/camp.gd`, `loot.gd`, `fx.gd`, `mk.gd` | лагеря, добыча, эффекты, построение геометрии |
| `scripts/*.gdshader` | песок и вода |
| `export_presets.cfg` | пресет экспорта Android |

Рендерер — Compatibility (OpenGL ES 3), подходит для большинства телефонов.
Физические слои: 1 — мир, 2 — герой, 3 — NPC, 4 — конь.
