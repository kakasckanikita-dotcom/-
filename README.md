# Пыль и Свинец

Вестерн с открытым миром, вид сверху. Территория Мескаль, 1889 год.
Вы — Эли Брэнсон, охотник за головами.

## Версия на Godot (основная) — папка `godot/`

**Запуск:**
1. Установите [Godot 4.3+](https://godotengine.org/download) (обычная версия, не .NET).
2. В менеджере проектов нажмите «Импорт» и выберите `godot/project.godot`.
3. Нажмите F5.

Картинок и звуков в проекте нет: персонажи, кони, здания и местность рисуются кодом,
звуки синтезируются при запуске. Рендерер — Compatibility, поэтому проект можно
экспортировать в браузер (Web), а также под Windows, Linux и macOS.

**Устройство проекта:**

| Файл | Что делает |
|---|---|
| `scenes/main.tscn` | главная сцена: мир, смена суток (CanvasModulate), интерфейс |
| `scripts/game.gd` | автозагрузка `Game`: характеристики героя, розыск, время, звуки, сохранение |
| `scripts/world.gd` | генерация мира, спавн персонажей, лагеря, погоня, день и ночь |
| `scripts/player.gd` | герой: движение, конь, стрельба, «Глаз ястреба» |
| `scripts/npc.gd` | бандиты, главари, горожане, шерифы, конная погоня |
| `scripts/horse.gd` | конь Буран |
| `scripts/bullet.gd` | пули (луч на каждом кадре, без пролёта сквозь цели) |
| `scripts/hud.gd`, `minimap.gd` | показатели, уведомления, карты, меню зданий |
| `scripts/gfx.gd` | процедурная отрисовка фигур |
| `scripts/ground.gd`, `decor.gd`, `obstacle.gd`, `building.gd`, `camp.gd`, `loot.gd`, `fx.gd` | местность, кактусы и скалы, здания, лагеря, добыча, частицы |

Физические слои: 1 — мир, 2 — герой, 3 — NPC, 4 — конь.

## Браузерный прототип — `web/index.html`

Первая версия на JavaScript, открывается двойным кликом.

## Что есть в игре
- Мир 4800×4800: пустыня, река с мостами, дороги, два города, восемь бандитских лагерей
- Конь: можно сесть и слезть, есть галоп с выносливостью, на свист прибегает
- Перестрелки: барабан на 6 патронов, перезарядка, разброс при стрельбе с коня
- «Глаз ястреба»: замедление времени, метки на целях и залп по всем отмеченным
- Розыск за головы у шерифа, награда за главаря
- Закон: преступления дают звёзды розыска, приходит конная погоня; от неё можно скрыться или заплатить штраф
- Салун (виски, покер, ночлег), лавка (патроны, аптечки, тоники), банк, который можно ограбить
- Смена дня и ночи с освещением, честь, добыча с тел, миникарта и большая карта, автосохранение

## Управление
WASD — движение · Мышь/ЛКМ — прицел/выстрел · Shift — «Глаз ястреба» · E — конь/двери ·
Пробел — галоп · H — свист · R — перезарядка · Q — аптечка · F — тоник · M — карта · Esc — закрыть

Клавиши привязаны к физическим кнопкам, поэтому работают и на русской раскладке.
